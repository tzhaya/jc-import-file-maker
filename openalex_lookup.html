自機関の ROR ID で OpenAlex を検索し、候補論文の DOI リストを出力します。出力した DOI は make_jc_importer の「DOIリスト一括取得」に貼り付けて取り込めます。

⚠ OpenAlex API Keyが設定されていません。設定しない場合、利用回数が制限されます（shared.js で設定できます）。
