# プライバシーポリシー

**最終更新日: 2026-06-28**

## 1. はじめに

「JAIRO Cloud インポート支援ツール」（以下「本拡張機能」）は、機関リポジトリ JAIRO Cloud (WEKO3) へのメタデータ一括インポートを支援する Chrome 拡張機能です。本ポリシーでは、本拡張機能が利用者のデータをどのように扱うかを明示します。

## 3. 取得・利用するデータ

### 3-1. 本拡張機能が取得しないデータ

本拡張機能は以下のデータを一切取得・収集しません。

- 個人を特定できる情報（氏名・メールアドレス・住所等）
- 閲覧履歴・ブラウジング情報
- ウェブページのコンテンツ（後述 3-4 のとおり、利用者がボタンを押した場合に限り、表示中ページの DOI を表す meta タグのみを一時的に読み取りますが、保存・送信は行いません）
- ユーザーの操作履歴・アクセス解析データ
- Cookie 等のトラッキング情報

### 3-2. 利用者が入力するデータ

利用者がフォームに入力したデータ（DOI、研究課題番号、ISSN、リポジトリ URL 等）は、利用者が「データ取得」「検索」等のボタンを押した際に、メタデータ取得の目的でのみ外部 API に送信されます。これらのデータはブラウザの内部処理にのみ使用され、提供者のサーバーや第三者に送信・保存されることはありません。

### 3-3. 設定データ（API キー）

- 本拡張機能の設定画面で利用者が入力した API キー（OpenAlex / CiNii / Open Policy Finder）は、ブラウザのローカルストレージ（`chrome.storage.local`）にのみ保存されます。
- これらの API キーは利用者の同一ブラウザ・同一プロファイル内でのみ使用され、各 API 提供元への認証以外の目的で送信されることはありません。
- 拡張機能をアンインストールするとローカルストレージの内容は消去されます。

### 3-4. 表示中ページからの DOI 自動取得

- 利用者が「ページからDOI取得」ボタンを押したときに限り、本拡張機能は現在表示中のタブのページから DOI を表す meta タグ（`citation_doi` / `prism.doi` / `DOI` / `dc.identifier`）および schema.org JSON-LD の identifier の値のみを一時的に読み取り、入力欄にセットします。
- 読み取りは利用者の明示的な操作時のみ実行され、ページの本文・閲覧履歴・その他のコンテンツは読み取りません。読み取った DOI は提供者のサーバーや第三者に送信・保存されることはありません。
- この機能はページへのスクリプト実行（`scripting`）を伴うため、初回利用時にウェブサイトへのアクセス許可をブラウザが確認します。許可しない場合、本機能（ページからの DOI 取得）は利用できません。許可後も、読み取るのは利用者がボタンを押したときの DOI の meta タグ・JSON-LD identifier のみであり、それ以外のページ内容を読み取ることはありません。

## 4. データの保存

本拡張機能の提供者はサーバーを持ちません。すべての処理は利用者のブラウザ内で完結し、提供者がデータを保持・閲覧することはありません。

## 5. 外部サービスへのアクセス

本拡張機能は以下の外部 API へアクセスし、利用者が入力したデータに基づくメタデータの取得を行います。

| サービス | 用途 | プライバシーポリシー |
|---|---|---|
| Crossref | DOI メタデータ取得 | https://www.crossref.org/operations-and-sustainability/privacy/ |
| OpenAlex | 著者・所属情報補完 | https://openalex.org/about |
| JaLC（ジャパンリンクセンター） | DOI メタデータ取得 | https://japanlinkcenter.org/top/policy.html |
| CiNii Research / KAKEN（国立情報学研究所） | NCID・科研費課題情報取得 | https://support.nii.ac.jp/ja/cinii/terms |
| Open Policy Finder（Jisc） | 学術誌の OA ポリシー取得 | https://www.jisc.ac.uk/website/privacy-notice |
| ROR（Research Organization Registry） | 研究機関識別子取得 | https://ror.org/privacy/ |
| WEKO3 リポジトリ各機関 | 機関リポジトリ検索（OpenSearch） | 各機関のプライバシーポリシーに従います |

API への問い合わせには、利用者が入力した DOI・課題番号・ISSN 等が含まれます。これらは各 API 提供元の利用規約・プライバシーポリシーに従って処理されます。利用者は各サービスのポリシーをご確認の上、本拡張機能をご利用ください。

## 6. データの第三者への提供

本拡張機能は、利用者のデータを上記 5. に挙げた API 提供元以外の第三者に提供しません。

## 7. リモートコード・トラッキング

- 本拡張機能はリモートコード（外部からの動的なスクリプト読み込み）を一切使用しません。すべての実行コードは拡張機能パッケージ内に同梱されています。
- 本拡張機能はアクセス解析ツール・広告 SDK・トラッキングピクセル等を一切使用しません。

## 8. 必要な権限について

本拡張機能は以下の権限を要求します。

- `storage`: API キーや設定の保存に使用します。
- `sidePanel`: サイドパネル UI 表示に使用します。
- `scripting`: 「ページからDOI取得」機能で、表示中ページの DOI を表す meta タグを読み取るために使用します。利用者がボタンを押したときに限り実行されます。
- `optional_host_permissions`（`http(s)://*/*`）: 上記の DOI 取得機能のために、利用者が「ページからDOI取得」ボタンを押したときにウェブサイトへのアクセス許可を実行時に要求します（インストール時には要求しません）。電子ジャーナルのドメインは出版社ごとに異なり事前列挙が不可能なため、広いパターンが必要です。許可は利用者が承認した場合のみ有効になり、ブラウザの設定からいつでも取り消せます。許可後も実際に読み取るのはボタン操作時の DOI の meta タグ・JSON-LD identifier のみで、ページ本文・閲覧履歴は読みません。
- `host_permissions`: CORS 制約のある学術 API（KAKEN・JaLC・Open Policy Finder・WEKO3 リポジトリ）への問い合わせに使用します。これらのドメインに対するアクセスは、利用者が機能を実行したときに限られます。Service Worker の fetch proxy は `ALLOWED_HOSTS`（3ホスト）のみを対象とし、それ以外のホストへの proxy は拒否します。詳細は [docs/chrome_store_permissions.md](chrome_store_permissions.md) を参照してください。

## 9. 利用者の権利

- 利用者はいつでも本拡張機能をアンインストールできます。アンインストールするとローカルストレージに保存された API キー・設定は消去されます。
- 拡張機能の設定画面から API キーを個別に削除することもできます。

## 10. ポリシーの変更

本ポリシーは予告なく改訂されることがあります。重要な変更は GitHub リポジトリのリリースノートまたは README にて告知します。改訂後のポリシーは本ページに掲載された時点で有効となります。
