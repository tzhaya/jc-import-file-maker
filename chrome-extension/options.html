JAIRO Cloud インポート支援ツール — 設定

APIキーはブラウザのローカルストレージに保存されます。外部に送信されることはありません。

JAIRO Cloud OpenSearch

OpenSearch検索タブを開いたときに自動入力されるリポジトリのURLを設定します。

OpenAlex API

未設定でも動作しますが、レート制限が厳しくなります。 OpenAlex で取得できます。

CiNii Research API（KAKEN連携・NCID取得に使用）

未設定でも基本機能は動作します。KAKEN XML APIを利用するには設定が必要です。 CiNii Research API で取得できます。

Open Policy Finder (OPF) API

雑誌のOAポリシー情報を取得します（CORS非対応のためChrome拡張経由でのみ動作）。 Open Policy Finder で取得できます。
